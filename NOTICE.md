# Project provenance notice

FocusLens AI is a new, independent implementation created for Montassar Ben Mesmia's public engineering portfolio.

It was informed by four exported branches from a collaborative academic AI prototype:

- face localization and recognition experiments;
- an attention-detection module;
- a facial-expression classification notebook;
- a combined detection and analytics prototype.

The archived attention README explicitly named **Firas Guesmi** as that module's contributor. FocusLens does not copy or claim authorship of that module. The original prototype's ownership and contribution history could not be fully reconstructed from the ZIP exports, so this repository describes its origin conservatively as collaborative.

For privacy, licensing, and reproducibility reasons, the following archive content was excluded:

- every photograph and generated sample-prediction image;
- all video/camera captures and prospective dataset folders;
- collected concentration CSV records;
- facial identity classifiers and label encoders;
- PyTorch, YOLO, KNN, preprocessing, and other serialized model artifacts;
- code that uploads raw frames, recognizes identities, or logs request bodies;
- copied dashboard pages and styles from the combined prototype.

All application code, tests, interface code, documentation, and synthetic-data logic in this repository were written anew for FocusLens.
